# AWS LAMBDA - TRANSACTIONS CRUD SERVICE
**Phụ trách:** Sinh viên 2 (SV2)  
**Nhiệm vụ Tuần 2:** Triển khai các hàm Lambda xử lý CRUD giao dịch chi tiêu:
- `create_transaction`: Ghi nhận giao dịch vào DynamoDB.
- `list_transactions`: Lấy danh sách giao dịch, lọc theo tháng/năm.
- `get_transaction`: Lấy chi tiết 1 giao dịch.
- `update_transaction`: Cập nhật thông tin giao dịch.
- `delete_transaction`: Xóa giao dịch.
