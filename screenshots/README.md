# THƯ MỤC ẢNH MINH CHỨNG (SCREENSHOTS)
Nơi lưu trữ ảnh chụp màn hình minh chứng cấu hình thật trên AWS Learner Lab để nộp báo cáo theo quy chuẩn của GVHD Huỳnh Xuân Phụng.

### Quy chuẩn ảnh bắt buộc:
1. Chụp toàn màn hình (Full Screen, không cắt viền).
2. Thấy rõ:
   - Account ID và Region `us-east-1` ở góc trên bên phải.
   - Đồng hồ máy tính thực tế ở góc dưới bên phải.
   - Thẻ Tags có đầy đủ `Project: ExpenseTracker` và `Owner: SVx_xxx`.

### Danh sách ảnh cần có trong Tuần 1:
- `01_iam_labrole.png`: Minh chứng khảo sát IAM `LabRole` (SV2).
- `02_security_group.png`: Minh chứng tạo Security Group `expense-tracker-sg` kèm Tags (SV2).
- `03_dynamodb_table.png`: Minh chứng tạo bảng DynamoDB `Transactions` On-Demand kèm Tags (SV2).
- `04_s3_buckets.png`: Minh chứng tạo 2 S3 Buckets kèm Tags (SV1).
