# THƯ MỤC HÓA ĐƠN MẪU (SAMPLE RECEIPTS)
**Phụ trách:** Sinh viên 1 (SV1)  

Nơi chứa 15-20 file hóa đơn mẫu (ảnh `.jpg`, `.png`, hoặc `.pdf`) phục vụ kiểm thử tính năng đọc hóa đơn bằng **Amazon Textract (AnalyzeExpense)**.

### Yêu cầu dữ liệu:
- Hóa đơn từ các chuỗi bán lẻ, siêu thị, nhà hàng (ví dụ: Highlands, Phúc Long, Co.opmart, WinMart, CGV...).
- Có hiển thị rõ các trường: Tên đơn vị bán lẻ (Vendor), Ngày tháng (Date), Danh mục sản phẩm (Line items) và Tổng tiền (Total).
